# Together 💕

A modern couple memory website built with Vue 3 + TypeScript + Vite.

## Features

- Love duration counter
- Couple profile hero banner
- Memory timeline
- Gallery
- Moments journal
- Bucket list
- Guestbook (future)

## Deployment

Designed for GitHub Pages deployment.

## Tech Stack

- Vue 3
- TypeScript
- Vite
- Tailwind CSS
